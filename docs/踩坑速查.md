# 踩坑速查（本机实测，2026-10-21）

装机过程中真实遇到的问题，按现象查。**先看"现象"，再照"处理"做。**

---

## 一、虚拟机根本开不了机

### 现象：`Cannot assign available PCI slot to 'ethernet0'`
**原因**：这台虚拟机的 PCI 槽位用满了（磁盘占 SCSI 控制器 + 3 个光驱占 IDE + 显卡 + USB），加网卡就挤爆。

**处理**：本项目模板里网卡是**关闭**的（学汇编不需要网络）。
- 若你确实要联网：把光驱减少到 1 个，或把磁盘从 SCSI 改成 IDE（腾出 SCSI 控制器槽位）

### 现象：`[msg.guestos.badname] Guest operating system 'win7pro' is not supported`
**原因**：新版 VMware 改了客户机 ID。

**处理**：`.vmx` 里写 `guestOS = "windows7"`（32 位），不是 `win7pro`。模板里已经是对的。

### 现象：`The IDE device (disks/CD-ROM) configuration is incorrect`
**原因**：IDE 从属设备没有主设备（VMware 里 `ide1:0/1` 是主通道主/从，`ide0:0/1` 是副通道主/从）。

**处理**：每个 `:1` 设备，前面必须有 `:0`。模板里是 ide1:0 + ide1:1 + ide0:0，全部合规。

### 现象：开机黑屏 / 装到一半卡死
**原因**：Win7 x86 **只能传统 BIOS 引导**，UEFI 会卡在无引导设备。

**处理**：`.vmx` 必须有 `firmware = "bios"`（模板已有）。

## 二、装系统时报错

### 现象：`Windows 无法分析或处理无人参与应答文件 … 第 65 行第 9 列`
**原因**：`wcm:` 命名空间只声明在 `<Disk>` 元素上，出了那个子树就是"未声明前缀"。

**处理**：必须声明在根元素：
```xml
<unattend xmlns="urn:schemas-microsoft-com:unattend"
          xmlns:wcm="http://schemas.microsoft.com/WMIConfig/2002/State">
```

### 现象：`应答文件中指定的组件或设置不存在`（oobeSystem 阶段）
**原因**：写了 Windows 8 才有的 OOBE 元素。

**处理**：Win7 只认这 6 个：`HideEULAPage`、`HideWirelessSetupInOOBE`、`NetworkLocation`、`ProtectYourPC`、`SkipMachineOOBE`、`SkipUserOOBE`。
**不要**写 `HideLocalAccountScreen`、`HideOEMRegistrationScreen`、`HideOnlineAccountScreens`。

### 现象：`Windows 无法完成安装。若要在此计算机上安装 Windows，请重新启动该安装`
**原因**：`specialize` 阶段的 `RunSynchronousCommand` 返回了非零退出码（Setup 视为致命）。最常见是 `reg.exe` 在 specialize 阶段 PATH 里找不到。

**处理**：本模板的应答文件里**已经不含任何 RunSynchronous**（VMware Tools 改为手动装）。若你自己加，必须写绝对路径并加 `& exit /b 0`：
```
C:\Windows\System32\cmd.exe /c C:\Windows\System32\reg.exe add ... & exit /b 0
```

### 现象：跳到"您想将 Windows 安装在何处"界面不动了
**原因**：应答文件的分区段写法不合规，Setup 回落到手动分区。

**处理**：`DiskConfiguration` 必须严格照微软模板：
- `CreatePartition` 用 `<Extend>true</Extend>`，**不要**同时写 `Size`
- `ModifyPartition` 要有 `<Letter>C</Letter>`
- `DiskID`、`WillWipeDisk` 放在 `<Disk>` 的**最后**

### 现象：手动点"下一步"报 `Windows 无法安装选择的分区进行准备`
**原因**：同上（分区段没生效），靠手动建分区又踩到磁盘状态问题。

**处理**：改好应答文件的分区段，别手动建。

## 三、系统装好了，但屏幕很小 / 黑屏

### 现象：Win7 只有 800×600，窗口中间一小块
**原因**：没装 VMware Tools（只有通用 VGA 驱动）。

**处理**：装 `02-VMwareTools\VMwareTools-11.0.6-Win7免补丁.iso` 里的 setup.exe，重启即可自适应。
临时办法：桌面右键 → 屏幕分辨率 → 选 1024×768 或 1280×1024。

### 现象：蓝屏 0x0000007B / 装完进不去
**原因**：磁盘控制器换了（比如从 SATA 改 IDE、或 NVMe）。

**处理**：Win7 没有 NVMe 驱动，**必须 SCSI 或 SATA**；建好后别乱改控制器。

### 现象：黑屏 / 花屏 / 极慢（12 代以上 CPU）
**处理**：`.vmx` 里这 3 行必须有（模板已有）：
```
monitor.virtual_exec = "hardware"
monitor.virtual_mmu = "software"
mks.enableVulkanRenderer = "FALSE"
```

## 四、VMware Tools 装不上

**原因**：新版 VMware 自带的 Tools（13.x）**不支持 Win7**；32 位 Windows 最高只支持 Tool s 12.4.x。

**处理**：
- Win7 SP1 没打补丁 → 用 **11.0.6**（包里那个「免补丁」的）
- 想用 12.4.9 → 先装 KB4490628 + KB4474419（SHA-2 签名支持）

## 五、实验箱连不上

### 现象：虚拟机里看不到 USB 设备
1. **USB 兼容性必须是 USB 2.0**（Win7 没有 xHCI 驱动），模板已是 2.0
2. 主机和虚拟机都要有 USB 仲裁服务在跑（VMware 装完默认就有）
3. 插上实验箱后 → 虚拟机菜单 → **可移动设备** → 选中 `ST-Ericsson USB Device` → **连接**

### 现象：设备管理器里是问号设备
右键 → 更新驱动程序 → 浏览计算机 → 指向 TPC 软件目录下的 `driver\`（里面有 `TPCA.inf`）→ 装好后显示 **`TPC Adapter`**。

### 现象：IDE 提示"硬件未连接"
- 实验箱电源开了吗（先开电源，再点硬件检测）
- 50 芯扁平线是否插好
- IDE 菜单「选项 → 硬件检测」
